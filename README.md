## 🔭 What I'm Working On

**📖 Arabic Calligraphy Dataset for ML**
Building and curating a structured ML-ready dataset of Arabic calligraphy styles for classification and recognition tasks — bridging Arabic cultural heritage with modern computer vision and ML pipelines.

**🤖 Tajweed Assistant (AI Agent)**
An AI-powered agent for Tajweed — the rules of Quranic recitation — helping learners identify and correct pronunciation rules using NLP and rule-based logic. A meaningful application of Arabic NLP in an underserved domain.

**🏥 Clinical RAG Pipeline**
Building a retrieval-augmented generation (RAG) system over clinical documentation using LangChain, Qdrant, and an open-source LLM — served via FastAPI. Designed for privacy-aware clinical NLP in hospital workflows.

**📊 Healthcare Appointment No-Show Risk Scoring System**
End-to-end ETL pipeline processing 110,000+ clinical records → PostgreSQL data warehouse → clinic-level KPI benchmarking → Power BI dashboard → AWS S3/Athena.
